# 🌿 GlowCare AI

GlowCare AI is an AI-powered skin and hair wellness assistant. It analyzes uploaded images to identify visibly observable characteristics and provides general skincare, haircare, and natural wellness suggestions.



 ✨ Features

- 📸 Skin, hair, and scalp image analysis
- 🔍 Visible characteristic identification
- 🌿 General skincare and haircare suggestions
- 💬 AI-powered follow-up conversation
- 📋 Conversation summary
  

 🛠️ Technologies

- Python
- Streamlit
- Google Gemini API
- Twilio WhatsApp API

⚙️ Setup

 1. Clone the repository

```bash
git clone https://github.com/amiyabiju04-byte/glowcare.git
cd glowcare
```

 2. Install dependencies

```bash
pip install -r requirements.txt
```

 3. Add API keys

Create:

```text
.streamlit/secrets.toml
```

and add your Gemini and Twilio credentials.

**Do not upload your API keys or `secrets.toml` to GitHub.**

 4. Run the application

```bash
streamlit run app.py
```

 ⚠️ Disclaimer

GlowCare AI provides general educational and wellness information. It does not diagnose medical conditions or replace professional medical advice.
